# Arduino Robotic Arm

A multi-axis robotic arm controlled using an Arduino Uno.

## Project Overview

This project started as a small servo-based robotic arm controlled by two
joysticks. I am gradually improving the mechanical design, electronics,
software, and control systems.

## Features

- Arduino Uno control
- 4 servo motors
- 2 joystick controllers
- External servo power supply
- Claw/gripper
- HC-05 Bluetooth control
- MPU6050 motion control
- Custom 3D-printed mechanical components
- Autodesk Fusion CAD designs

## Hardware

- Arduino Uno
- Servo motors
- 2 × joystick modules
- HC-05 Bluetooth module
- MPU6050
- External 5V power supply
- Custom robotic-arm components

## Current Status

The original prototype is working. I am currently redesigning the
mechanical structure and improving the control system.

## Future Goals

- Redesign the arm in Autodesk Fusion
- 3D print the new components
- Upgrade the high-load servos
- Improve movement smoothness
- Add wireless control
- Add motion-based control
